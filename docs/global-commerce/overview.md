# Global Commerce

SolydFlow helps businesses sell across multiple countries by combining localized pricing, multi-currency support, and payment provider routing.

Rather than processing payments directly, SolydFlow routes transactions through your configured payment providers while providing a unified purchase, recovery, and reconciliation experience.

## Capabilities

Global Commerce in SolydFlow includes:

* Multi-currency Products
* Regional pricing
* Geo-IP package selection
* Local and international payment provider support
* Unified transaction tracking

## How It Works

Customers are automatically presented with the most appropriate Package based on their location.

If no localized Package is available, SolydFlow defaults to the Product's USD Package.
