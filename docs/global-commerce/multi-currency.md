# Multi-Currency

SolydFlow allows a single Product to offer multiple localized Packages, each with its own currency and price.

## Package Selection

When a customer initiates a purchase, SolydFlow automatically selects the most appropriate Package using Geo-IP.

If a localized Package is unavailable, SolydFlow defaults to the Product's USD Package.

## Example

```text
Premium Monthly
├── ₦5,000 (NGN)
├── KSh500 (KES)
└── $4.99 (USD)
```

Each Package represents the same Product while allowing businesses to define pricing appropriate for different markets.

## Benefits

* Localized pricing
* Improved conversion rates
* Consistent Product management
* Automatic Package selection
