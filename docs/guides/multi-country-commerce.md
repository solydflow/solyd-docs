# Multi-Country Commerce

## Best For

* Businesses operating across multiple regions
* International digital products
* Multi-currency applications

## You'll Learn

* How to configure localized pricing
* How Geo-IP package selection works
* How to support multiple currencies

## Recommended Flow

1. Create your Product.
2. Add a Package for each supported currency.
3. Configure regional pricing.
4. Connect the appropriate payment providers.
5. Test localized purchases using the Sandbox.
6. Launch globally.

## Package Selection

SolydFlow automatically selects the appropriate Package using Geo-IP.

If no localized Package is available, the USD Package is used by default.
