# SaaS

## Best For

* SaaS platforms
* Membership applications
* Subscription businesses

## You'll Learn

* How to model subscription plans
* How to configure Products and Packages
* How to grant Entitlements
* How to launch recurring billing

## Recommended Flow

1. Create a Project.
2. Create Products for each subscription tier.
3. Add localized Packages for supported currencies.
4. Configure your purchase experience:

   * SolydFlow Paywall
   * Custom SDK/API integration
5. Grant Entitlements after successful purchase.
6. Test the complete flow in the Sandbox.
7. Go live.

## Typical Product Structure

```text
Starter
├── NGN Package
├── KES Package
└── USD Package

Pro
├── NGN Package
├── KES Package
└── USD Package
```
