# EdTech

## Best For

* Learning platforms
* Online courses
* Exam preparation
* Digital classrooms

## You'll Learn

* How to monetize educational content
* How to manage learner access
* How to support regional pricing

## Recommended Flow

1. Create Products for each learning plan.
2. Configure localized Packages.
3. Map Products to Entitlements.
4. Present a Paywall or custom purchase flow.
5. Grant access after successful purchase.

## Typical Products

* Credit-based Learning Plan
* Monthly Learning Plan
* Annual Learning Plan
* Lifetime Access
