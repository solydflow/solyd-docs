# Marketplaces

## Best For

* Digital marketplaces
* Service marketplaces
* Classified platforms

## You'll Learn

* How to monetize marketplace features
* How to sell premium listings
* How to offer seller subscriptions

## Common Monetization Models

* Seller subscriptions
* Featured listings
* Listing upgrades
* Premium marketplace features

## Recommended Flow

1. Create Products.
2. Configure localized Packages.
3. Present your preferred checkout experience.
4. Grant marketplace features through Entitlements.

## Note

SolydFlow manages payment orchestration and revenue infrastructure. Settlement is performed by your configured payment provider.
