# Mobile Apps

## Best For

* iOS applications
* Android applications
* Cross-platform apps

## You'll Learn

* How to configure in-app purchases
* How to support multiple app stores
* How to manage subscriptions and one-time purchases

## Recommended Flow

1. Create your Project.
2. Create Products.
3. Configure Packages for each supported store.
4. Associate Apple Product IDs and Google Product IDs where applicable.
5. Integrate the SolydFlow SDK.
6. Test purchases in the Sandbox.
7. Publish your application.

## Purchase Experience

Choose either:

* SolydFlow Paywall
* Custom in-app purchase flow using the SDK
