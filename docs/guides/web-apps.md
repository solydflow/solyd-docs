# Web Apps

## Best For

* Web applications
* Customer portals
* Membership platforms

## You'll Learn

* How to integrate web payments
* How to use hosted Paywalls
* How to build a custom checkout

## Integration Options

Choose one of the following:

* Hosted SolydFlow Paywall
* Custom checkout using the SDK or API

Both approaches use the same Products, Packages, and Entitlements.

## Recommended Flow

1. Create Products.
2. Configure Packages.
3. Connect a payment provider.
4. Configure your checkout.
5. Test purchases.
6. Launch.
