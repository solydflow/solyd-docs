# Going Live

Once your project has been fully tested, you can begin processing live transactions.

## Before You Switch

Confirm that:

* Production credentials are configured.
* Live API keys are being used.
* Webhook endpoints are reachable.
* Products and Packages are correctly configured.
* Payment providers are operational.

## Live Mode

When using Live Mode:

* Live API keys replace test keys.
* Production provider credentials are used.
* Live transactions are recorded in your project.

Test and Live environments remain isolated from one another.

## After Launch

After your first live transactions:

* Monitor webhook deliveries.
* Verify successful entitlement granting.
* Review transaction status.
* Confirm reconciliation completes successfully.
