# Troubleshooting

This section helps you diagnose and resolve common issues when integrating SolydFlow.

Most payment issues can be investigated using transaction history, webhook events, recovery workflows, and reconciliation results.

## Common Issues

* Payment remains pending
* Webhook not received
* Entitlement not granted
* Transaction state mismatch
* Provider-specific errors

Before troubleshooting, verify that:

* Your API keys are correct.
* Payment provider credentials are configured.
* Webhook endpoints are reachable.
* Your project is using the correct environment.
