# Entitlement Not Granted

If a successful purchase does not unlock the expected features, verify the Product and Entitlement configuration.

## Verify

* Product configuration
* Package configuration
* Entitlement mapping
* Transaction status

Ensure the transaction has reached a successful final state before granting access.

## Resolution

Use transaction history and reconciliation results to determine whether the purchase completed successfully.
