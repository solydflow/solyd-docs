# Audit Logs

SolydFlow maintains operational audit logs to help administrators monitor important platform activities.

Audit logs provide visibility into changes affecting projects and payment infrastructure.

## Logged Activities

Examples include:

* Project configuration changes
* Operational webhook activity

Audit logs are intended to support operational visibility and troubleshooting.

## Using Audit Logs

Audit logs can help teams:

* Investigate configuration changes
* Review operational activity
* Troubleshoot payment workflows
* Support incident investigations
