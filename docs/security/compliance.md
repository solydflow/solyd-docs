# Compliance

SolydFlow is designed with security best practices to help businesses build secure payment workflows.

The platform protects sensitive data through encrypted communication, secure credential storage, authenticated API access, and webhook verification.

## Current Focus

Current security capabilities include:

* Encryption in transit
* Encryption at rest
* Secure API authentication
* Protected credential management
* Webhook verification
* Operational audit logging

## Compliance Roadmap

Additional compliance guidance and certification information will be published as new compliance capabilities become available.

## Shared Responsibility

While SolydFlow provides the infrastructure required for secure payment processing, businesses remain responsible for securing their own applications, user authentication, and operational processes.
